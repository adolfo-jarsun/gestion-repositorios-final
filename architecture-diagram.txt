# Diagrama de Arquitectura del Sistema

## 1. Descripción General

El sistema está diseñado bajo una arquitectura cliente-servidor
con separación clara entre frontend, backend y base de datos.

Se adopta una arquitectura en capas para facilitar el mantenimiento
y escalabilidad futura.

---

## 2. Componentes

- Cliente Web (Frontend)
- API Backend (REST / GraphQL)
- Base de Datos Relacional
- Servicio de Autenticación
